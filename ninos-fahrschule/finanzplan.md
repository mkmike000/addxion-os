# Finanzierungsskizze

- Eigenkapital / vorhandene Fahrzeuge: offen (nicht genannt).
- Hausbank + Bürgschaftsbank / Gründungskredit.

- Förderung: AVGS/Gründungsberatung prüfen, KfW-Gründerkredit, regionale Programme. Kein Automatismus.
