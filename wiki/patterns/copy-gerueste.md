# Eine Aussage

Ein Gerüst ordnet Sätze. Es ersetzt nicht Leitung, Angebot oder Beweis.

# Katalog

Kurze Copy

| Gerüst | Ablauf | Nutzen |
| --- | --- | --- |
| AIDA | Attention, Interest, Desire, Action | Erster Screen, Anzeige |
| PAS | Problem, Agitate, Solve | Schmerz ist schon klar |
| PASOPA | PAS plus Offer, Proof, Action | Leadseite, Download |
| BAB | Before, After, Bridge | Zustand zeigen, nicht nur Schmerz |
| FAB | Feature, Advantage, Benefit | Produkt bekannt, Nutzen fehlt |
| 4Ps | Picture, Promise, Prove, Push | Landing, Magnet |
| SLAP | Stop, Look, Act, Purchase | sehr kurze Anzeige |

Länger oder narrativ

| Gerüst | Ablauf | Nutzen |
| --- | --- | --- |
| Hook Story Offer | Haken, Geschichte, Angebot | Social, Video, LinkedIn |
| PASTOR | Problem, Amplify, Story, Testimony, Offer, Response | hohes Ticket, Vertrauenslücke |
| QUEST | Qualify, Understand, Educate, Stimulate, Transition | lange Salespage |
| ACCA | Awareness, Comprehension, Conviction, Action | erklärungsbedürftig |
| StoryBrand | Kunde Held, wir Guide, Plan, Call, Failure, Success | About, Case, nicht erste Ad |
| Jobs To Be Done | Job in einer Situation | Briefing, nicht Satzbau |

AFOREST ist Rhetorik in einem Block (Fakten, Wiederholung, Dreier), kein Funnel.

# Was ADDXION nimmt

| Fläche | Gerüst |
| --- | --- |
| Labor-Script addxion.ai | BAB (schon gesetzt: Vorher, Schnitt, Nachher, Zeiger) |
| Ort-Video this.type | Hook Story Offer, Schritte vor Ergebnis |
| LinkedIn oder Feed-Text ohne Download | Hook Story Offer oder PAS |
| Leadseite, einseitiger Download | PASOPA oder 4Ps |
| Leistungs- oder Produktkarte | FAB, Nutzen im Title laut [Marketing-Sites](marketing-sites.md) |
| Hero addxion.com | AIDA, eine Handlung |
| Erklärung Agent-Runtime | ACCA, nicht PAS allein |
| Erstgespräch | nicht diese Tabelle, sondern [Bedarfsermittlung](bedarfsermittlung.md) |

PAS verkauft das Problem. BAB verkauft den Zustand danach. 4Ps verkauft den Download. Hook Story Offer trägt den Feed.

# Lesart des Swipe vom 2026-09-17

Der fremde Text ist PAS plus Proof-Claim plus Offer: Problemliste, teure Folge, Namen des Magneten, Zahl und Frist, CTA. Struktur brauchbar. Inhalt nicht kopieren. „120+ SaaS-Projekte“ und „kaum bekannte Strategien“ sind fremde Behauptungen.

# Nicht tun

- Gerüst wählen, bevor Ende, Schritt und Event stehen.
- Zwei Gerüste in einem Stück stapeln.
- Zahlen, Fristen, Projektmengen erfinden, damit PASOPA voll wirkt.
- Feature-Stack (LiveKit, LangGraph, Elixir) in den ersten Block.
