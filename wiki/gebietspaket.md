# Ein Satz

Gebietstypische Prüfungsstellen so vorbereiten, dass der Erstversuch Praxis besteht. Richtung Durchfallquote 0, messbar Schule für Schule.

# Vorhaben

Eigenes Geschäft unter ADDXION, nicht nur eine Agenturleistung. Kunde ist die Fahrschule. Produkt ist das Gebietspaket (Videos + Player + Lizenz). Wirkung ist die Erstversuch-Quote Praxis B/BF17.

0 heißt: Stellen, die das Paket abdeckt, sollen aufhören, Erstversuche zu kippen. Fahrzeugbeherrschung und Theorie liegen außerhalb.

# Modell

Lizenz an die Fahrschule. Flat, Seat oder Pilot gegen Daten. Schule setzt den Schülerpreis. White-Label = Name der Schule auf dem Paket.

# Stand

Phase 0. Keine Unterschrift, kein gedrehtes Gebiet, keine Baseline.

# Offen

- Ziel: Vorhaben mit einer Pilotschule im Gebiet Gütersloh/Bielefeld in der Messung.
- Ist: Karte und Modell gelten.
- Lücke: Produkt und Vertrag fehlen.
- Zu klären: erste Schule; ob Player eigene App oder White-Label-Seite wird.
