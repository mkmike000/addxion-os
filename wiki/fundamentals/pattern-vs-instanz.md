Pattern = abstrakt, wiederverwendbar. Framework = eigenes Vertragssystem mit Version und Slots; sitzt zwischen Pattern und Instanz, die Instanz pinnt. [Framework](../patterns/framework.md). Instance = Code und Laufzeit (n8n, Webflow, Produkt-Repo). Die Instanz führt aus; was gilt, steht hier. Kein Wissen in Instanz-`MASTERPLAN.md` duplizieren.
