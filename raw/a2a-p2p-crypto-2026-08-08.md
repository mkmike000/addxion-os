# A2A im Chat (Stand der Recherche damals)

A2A = Agent2Agent-Protokoll. Offener Standard für Kommunikation zwischen undurchsichtigen Agenten. Ursprung Google (April 2025), später Linux Foundation. JSON-RPC 2.0 über HTTP(S), Agent Cards, Tasks. Agent kann Client und Server sein. Mesh möglich, nicht nur Hub-and-Spoke. MCP bleibt Agent-zu-Tool; A2A bleibt Agent-zu-Agent.

Erwähnte Ergänzungen außerhalb des Kernprotokolls: x402-Micropayments, ledger-anchored Agent Cards, DIDs, AP2 (Agent Payments).
